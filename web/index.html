sqz
CLI GitHub

Convert images to any format, as small as they can be.

PNG, APNG, GIF, WebP, AVIF and JPEG in and out, HDR included. You get a lossless file plus lossy versions tuned to the visual quality you choose, side by side, so you can pick the one you want. Everything runs in your browser. Nothing is uploaded.

Convert to

SSIMULACRA2 score. Lossy versions use the smallest setting that still reaches it.

Options
Drop images here or click to choose, or paste. PNG · APNG · GIF · WebP · AVIF · JPEG. Then press Compress.

      Same engine on the command line

      $ npx @joseprio/sqz animation.gif                    # → animation.png (APNG)
$ npx @joseprio/sqz -t webp -m lossy photo.png       # → photo.quantized.webp + photo.lossy.webp
$ npx @joseprio/sqz -t avif -m lossy -T 70 -r photos -o out/
$ npx @joseprio/sqz -t jpeg -T 85 hdr.avif                # → hdr.jpg (Ultra HDR)
$ npx @joseprio/sqz -f --max *.png                   # recompress in place
